=== 2026-10-01, F21 corrected after review ===
- /code-review high returned 11 findings on the first F21 commit, four of them major, and they are fixed: the Chrome probe was Linux-only so the harness would have refused to start on the Mac (Chrome channel is the default again, --chromium=/PERF_CHROMIUM names a binary elsewhere); HEADLESS defaulted from DISPLAY, which macOS never sets, so a Mac run would silently have gone headless (now headful on darwin, --headful/--headless override); the 240-frame preload wait was not route-aware, costing 120 s per anime run and writing a timeout into the result that read like a page failure; and the documented cause of the wheel factor was wrong.
